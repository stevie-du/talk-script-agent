# 广告法禁用词库

> 依据《中华人民共和国广告法》第九条及各平台执行细则整理。
> 用途：生成后自查，命中即改写。谐音、拆分、变体同样会被判定违规。

## 1. 绝对化用语（最高频雷区）

### "最"字系列
最、最佳、最优、最好、最大、最小、最高、最低、最新、最安全、最有效、最便宜、最低价、全网最低、最先进、最划算、最受欢迎、顶级、极致、天花板、巅峰、顶尖、史上最强、行业之最、性价比最高

### "第一 / 唯一"系列
第一、全网第一、全国第一、销量第一、行业第一、NO.1、TOP1、独一无二、仅此一家、仅此一款、唯一、独家、全球首发、首家、冠军、领跑者、行业龙头、独占市场

### "级 / 极 / 首 / 国"系列
国家级、世界级、极品、尖端、终极、首选、首家、王牌、顶尖工艺、殿堂级、填补行业空白

### 无法验证的绝对化描述
行业领先、领导者、销量冠军、绝无仅有、史无前例、万能、绝对、永久、无敌、性价比之王、无与伦比

## 2. 虚假承诺与功效断言

100%、百分百、彻底、零缺陷、无瑕、完美、根治、全部有效、永不反弹、零失败、百分百见效、无效退款、假一赔十、永久售后、百分百赔付

## 3. 虚假营销与逼单话术

清仓倒闭、老板跑路、最后一天、仅限今天、不买就亏、再不抢没了、马上涨价、错过再等一年、手慢无、抢爆、疯抢、万人秒杀、亏本甩卖、跳楼价

**注**：限时活动若真实，必须写明确切起止日期，禁止"仅此一次""随时结束"等模糊表述。

## 4. 权威虚假背书

央视上榜、央视推荐、政府专供、特供、国宴专用、官方认证、官方唯一授权、政府扶持、三甲医院认证、驰名商标、质量免检、国家级检测认证、名医研发、专家推荐

**注**：无检测报告不得提"检测认证"；无授权不得提"官方""政府"。

## 5. 电梯行业专用高危区（重点自查）

以下表述在电梯行业高频出现，全部违规或高风险：

| 禁用表述 | 风险 | 合规替换 |
|---|---|---|
| 绝对安全、100% 安全 | 绝对断言 | 具备多重安全保护装置 |
| 零事故、零故障 | 无法验证 + 绝对断言 | 具体数据可查时才写，否则不提 |
| 永不困人、永不故障、永久免维护 | 绝对承诺 | 响应及时、定期维保（配具体周期） |
| 最安全的电梯、行业第一品牌 | 极限词 | 市场保有量较大（需数据支撑） |
| 最先进的技术 | 极限词 | 采用成熟可靠的技术方案 |
| 政府扶持、政府补贴 | 虚假背书 | 符合条件的老旧小区可申请财政补助，以当地政策为准 |
| 包过检、保证通过验收、包拿证 | 无法兑现承诺 | 配合完成检验前的整改与资料准备 |
| 终身免费维保 | 无法兑现 | 质保期内免费，写清具体年限 |
| 全网最低价、全市最低 | 极限词 | 价格实惠、性价比突出 |

## 6. 合规替换速查

| 想表达 | 换成 |
|---|---|
| 最好 / 最先进 | 表现稳定、成熟可靠、用户反馈良好 |
| 第一 / 唯一 | 市场保有量较大、品牌专属、市面少见 |
| 绝对 / 100% | 多数情况下、大部分场景、通常 |
| 永久 / 永不 | 长期、长期使用、在规范保养下 |
| 万能 / 全覆盖 | 适配多数场景、覆盖常见需求 |
| 根治 / 彻底解决 | 有效改善、显著降低 |

## 7. 自查方式

生成后逐条扫描：**"最""第一""唯一""绝对""100%""永久""顶级""首选""万能""冠军""领先""国家级""官方认证"** 及其变体。命中即替换，并在输出中记录改写项。
