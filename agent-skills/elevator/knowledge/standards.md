# 电梯行业标准、法规与术语库

> 本文件为**索引级**知识库：只存编号、名称、关键口径，不存标准全文（标准文本有版权，且会换版）。
> 校验日期：2026-09-06。**每次引用前确认版本是否仍现行。**

## 使用原则

1. **不确定就不写编号**。写错编号比不写更损害专业度。
2. 引用时格式为：`《电梯维护保养规则》（TSG T5002-2017）` 或口语化为 `按照电梯维保规则的要求`。
3. 口播脚本中**编号点到为止**，不要把条款号念出来（观众听不懂，还占字数）。
4. 若发现编号可能已换版，改用标准名称，并在输出中提示用户核实。

## 四、维保周期口径

按 TSG T5002《电梯维护保养规则》，维保项目分为四类：
**半月、季度、半年、年度**

生成维保科普时周期表述必须落在这四类上，不要自造"每月维保""双周保养"等说法。

## 五、核心术语（规范说法 → 口语解释）

| 规范术语 | 口语化解释（用于脚本） |
|---|---|
| 曳引机 | 电梯的动力主机，相当于"发动机" |
| 制动器 / 抱闸 | 断电时自动抱死，防止轿厢移动 |
| 限速器 | 电梯的速度监控器 |
| 安全钳 | 速度异常时把轿厢卡在导轨上 |
| 限速器-安全钳联动 | 检测超速后机械制动的一套装置 |
| 缓冲器 | 井道底部最后一道缓冲保护 |
| 钢丝绳 / 悬挂装置 | 承载轿厢的钢丝绳，通常多根独立 |
| 对重 | 平衡轿厢重量的配重块 |
| 层门 / 轿门 | 楼层门 / 轿厢门 |
| 光幕 / 安全触板 | 门上的防夹感应装置 |
| 控制柜 | 电梯的"大脑" |
| 五方对讲 | 轿厢、机房、值班室等五处通话系统 |
| 定期检验 | 每年一次的法定检验 |
| 自行检测 | 使用单位按规定开展的检测 |
| 平层 | 轿厢与楼层地面对齐的位置 |

## 六、禁止输出的内容类型

- 具体拆机步骤、接线方法、参数调整数值
- 短接门锁、屏蔽安全回路等违规操作方法
- 故障码清除流程
- 绕过定期检验的做法

**原因**：电梯属特种设备，相关作业需持证进行。科普可讲**原理**和**周期**，不可讲**操作方法**。
