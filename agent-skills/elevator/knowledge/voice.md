# 口语化与人设声音（写成"说话"，不是"写文章"）

口播稿 = 一个人对着镜头说话的文字版。衡量标准只有一条：**念出声不拗口、不像念稿**。

## 度的把握：口语化 ≠ 俚语化（最容易矫枉过正的地方）

**口语化是"去掉书面腔"，不是"加俚语"。** 两者天差地别：

- ✅ 口语化（对，默认档）：短句、自然连接、具体细节、像专家在跟你聊
- ❌ 俚语化（错，过度档）：好家伙、撂挑子、扔半道上、整栋楼骂你、绝绝子

**按人设/平台/受众切档**，不要一刀切：

| 场景 | 推荐 style / audience | 口语度 |
|---|---|---|
| 物业业委会 / 开发商总包 / 政府旧改 / 品牌官方号 | 权威科普 / 严肃警示；专业受众 | **自然但克制**：用短句和具体数字，但不用俚语、不情绪化攻击 |
| 业主乘客 / 视频号泛科普 | 亲和接地气 | **自然**：可带轻口头禅（"你想啊""说白了"），不骂人 |
| 抖音年轻人 / 搞笑人设 | 幽默玩梗 | **可放开**：允许俚语与夸张，但仍是电梯行业内容，不低俗 |

**过度口语化负面清单（命中任一条就收一格）**：
- [ ] 俚语/网络梗堆砌（好家伙、撂挑子、绝绝子、家人们谁懂啊）
- [ ] 情绪化攻击或贬低（整栋楼骂你、厂家脸红、智商税）
- [ ] 为了接地气编浮夸细节（没依据的"修一次大几万"应改为具体或占位）
- [ ] 脏话、擦边、制造焦虑恐吓

**校准口诀**：专业品牌要"像内行在聊，不像主播在演"。具体细节和短句是你的武器，俚语和情绪化是雷区。

## 人类说话的 6 个特征（每条对照改写）

1. **有碎句和口头禅**
   - 加：`哎` `我跟你说` `你猜怎么着` `结果呢` `说白了` `你想啊`
   - 但"说白了/其实/不得不说"连用超过 1 次就砍
2. **有具体的人和事**（最重要，缺这个就是 AI 味）
   - 必须含 ≥1 个具体细节：真实小区名/化名、"王阿姨家那台"、具体数字（"困了 23 分钟""修一次大几万"）、真实尴尬场面
   - 抽象名词（"安全保障""乘梯体验"）一律翻译成人话
3. **节奏忽快忽慢，不工整**
   - 混排 2-3 字碎句与 15-20 字长句，禁止每段等长
   - 不用排比三连占满一段；要列点只列 1-2 个，第三个改碎句带过
4. **用大白话替术语**
   - 钢丝绳 → "那几根扛着的钢缆"；制动器 → "刹车"；平层 → "停得准不准"
   - 术语不是不能用，是第一次出现用大白话带一下
5. **有情绪和态度**：烦躁 / 无奈 / 得意 / 吐槽，不是中立播报
   - 加一句带态度的："整栋楼骂你""厂家自己都脸红"
6. **收尾不喊口号**
   - 禁："值得被认真对待""让生活更美好""守护每一次出行"
   - 改：一句大白话，或一个勾互动的反问

## 人话 vs AI 话（对照范例，撰写时脑内替换）

| AI 话（删） | 人话（写） |
|---|---|
| 定期维保是保障乘梯安全的重要举措 | 电梯你不保养，它真敢给你撂挑子 |
| 电梯是天天高负荷运行的设备，钢丝绳会磨损 | 你想啊，一天上下几十趟，那几根钢缆天天绷着，能不累吗 |
| 我们提供专业高效的维保服务 | 我们就是干这个的，比你想象中较真 |
| 这是强制要求，不是建议 | 规矩是死的——15 天一次，国家定的，没商量 |
| 综上所述，请重视电梯安全 | 别等困人了才想起来，到时候骂谁都没用 |

## 老炮人设声音样本（开场三选一，禁用"你有没有想过"）

- "哎，我跟你说个真事——"
- "昨天一师傅跟我吐槽，说现在……"
- "这事儿我见得太多了，今天非得掰扯清楚。"

## 自检动作（写完必做）

把稿子念出声一遍。哪里拗口、哪里像念说明书、哪里听着"端着"，改哪里。
如果念完觉得自己像播音员在背稿，整篇重写腔调，别只改词。
