# AI 味自查清单（撰写后逐条过，不过不算完稿）

每条命中就改，改完再读一遍。目标是"念出声不像念稿"。

## 一、结构味（最显眼）

- [ ] **排比三连占满一段** → 只留 1-2 个，第三个改碎句带过（"还有个更绝的，后面说"）
- [ ] **对仗工整的并列句** → "钢丝绳会磨、制动器会老、门机可能顿" 这种全平行结构，打散成口语
- [ ] **每段等长、无起伏** → 强制混排 2-3 字碎句和长句
- [ ] **"第一/第二/第三"清单体** → 除非必要，改"先说最要命的""还有个"

## 二、词藻味

- [ ] **填充词堆叠**：`其实` `说白了` `不得不说` `值得一提的是` `综上所述` 连用超 1 次 → 砍
- [ ] **抽象名词收尾/堆砌**：`安全保障` `乘梯体验` `重要举措` `核心价值` → 翻成人话
- [ ] **教科书口吻**：`按规范` `根据相关标准` `应当指出` → 改 `规矩是这么定的` `国家要求 15 天一次`
- [ ] **口号式收尾**：`值得被认真对待` `让生活更美好` `守护每一次出行` → 换大白话或反问

## 三、内容味（最致命）

- [ ] **通篇零具体**：没有真实人名/地名/数字/场景 → 必须补 ≥1 个具体细节
- [ ] **全程中立无情绪** → 加一句带态度的（吐槽/得意/无奈/烦躁）
- [ ] **像说明书不像人** → 把"应该怎么做"改成"我见过/我建议你"

## 四、开场禁区

- [ ] `你有没有想过` `在这个……时代` `今天我们来聊` `众所周知` → 换 voice.md 里的老炮开场

## 五、最终朗读测试

- [ ] 念出声，全程不拗口、不端着 → 通过
- [ ] 念完像播音员背稿 → 整篇重写腔调
