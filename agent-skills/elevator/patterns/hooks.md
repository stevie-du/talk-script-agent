# 开场钩子库与风格模板

## 一、钩子库（前 3 秒定生死）

按类型选用，**同一主题跑多版时应换不同类型**，避免 5 版一个样。

| 类型 | 结构 | 电梯行业实例 |
|---|---|---|
| 反常识 | 打破一个你以为是常识的认知 | `电梯真的会掉下去吗？干了十几年，我告诉你：概率比中彩票还低。` |
| 场景代入 | 描述受众经历过的具体场景 | `早上赶电梯，门开了，里面黑着灯——你敢进吗？` |
| 悬念提问 | 抛问题，答案压后 | `被困电梯，第一件事做什么？九成的人第一反应是错的。` |
| 损失厌恶 | 指出一个正在发生的风险 | `你家电梯的这个标志，超过这个日期还在用，就是在违法。` |
| 身份背书 | 用从业者身份建立信任 | `我修了十五年电梯，今天就说说我们内部人自己怎么乘电梯。` |
| 数据冲击 | 用具体数字开场（须有来源） | `一台电梯，每天运行两百次，一年就是七万三千次。` |
| 对比反差 | 前后 / 新旧 / 正反对比 | `同样两台电梯，一台用了十年还稳，一台三年就毛病不断，差在这一件事。` |
| 直接痛点 | 一句话戳中 | `加装电梯，一楼不同意，多半是这一步没做。` |
| 故事开场 | 短场景叙事 | `上周有个小区，业主被困二十分钟，原因特别简单。` |
| 误解纠正 | 点名一个流传很广的错误说法 | `很多人说被困电梯会窒息，这个说法害人不浅。` |

### 钩子禁用清单

- ❌ `大家好，我是……`（自我介绍放在钩子后面或干脆不放）
- ❌ `今天给大家讲讲……` / `今天来聊聊……`
- ❌ `你知道吗？`（过度使用，已无吸引力）
- ❌ `随着……的发展`（书面语开场）
- ❌ 长铺垫、背景介绍、寒暄

### 钩子与平台匹配

| 平台 | 推荐钩子类型 |
|---|---|
| 抖音 | 反常识、悬念提问、直接痛点（强度最高） |
| 小红书 | 场景代入、故事开场、身份背书 |
| 视频号 | 身份背书、场景代入、误解纠正（避免惊悚） |
| B站 | 反常识、悬念提问（可学术化） |

## 二、风格语气模板

### 权威科普
- **语气**：平实、准确、有分寸，不煽情
- **句式**：陈述句为主，适当用短句强调
- **用词**：规范术语，必要时立刻口语化解释（`限速器，简单说就是电梯的速度监控器`）
- **避免**：夸张修辞、感叹号、绝对判断
- **适用**：政策解读、标准科普、技术解析、B站/视频号

### 亲和接地气
- **语气**：像邻居师傅聊天
- **句式**：短句、口语词（"其实""说白了""你就记住"）、适当反问
- **用词**：术语后必须跟一句大白话
- **避免**：书面语连接词（因此、由此可见、综上所述）
- **适用**：业主科普、安全常识

### 幽默玩梗
- **语气**：轻松、自嘲、有梗
- **句式**：夸张对比、反转
- **用词**：网络语适度，不过时不过量
- **避免**：拿安全事故开玩笑、拿特定人群开玩笑、低俗梗
- **红线**：**涉及困人、伤亡的话题一律不得用幽默风格**

### 严肃警示
- **语气**：郑重、有分量、节奏慢
- **句式**：短句、停顿多、重复关键动作
- **用词**：准确、不加修饰
- **适用**：违规操作警示、事故预防、监管要求
- **注意**：警示不等于恐吓，要给明确可行的正确做法

### 销售转化
- **语气**：热情但不油腻，专业且可信
- **结构**：痛点 → 后果 → 方案 → 证据 → 行动
- **用词**：具体（数据、年限、响应时长）优于形容词
- **避免**：极限词、逼单话术、虚假承诺（见 `ad-law.md`）
- **关键**：**每提一个卖点，必须配一个证据**（案例、数据、资质）

## 三、风格与受众交叉建议

| 受众 | 推荐风格 | 说明 |
|---|---|---|
| 业主乘客 | 亲和接地气 / 严肃警示 | 懂设备少，怕专业词 |
| 物业 / 业委会 | 权威科普 | 关心责任边界和合规 |
| 维保公司 | 权威科普 | 同行，术语可直接用 |
| 开发商 / 总包 | 权威科普 / 销售转化 | 关心成本、工期、验收 |
| 经销商 / 渠道 | 销售转化 | 关心政策和利润 |

## 四、口语化硬性检查

生成后逐句检查：

1. 单句超过 25 字 → 拆开
2. 出现"因此""由此可见""综上所述""值得注意的是" → 删掉
3. 出现"进行XX""实现XX""提供XX保障"这类书面动宾 → 改成口语动词
4. 连续三句以上长度相同 → 打断节奏
5. 有可以删掉还不影响意思的词 → 删掉

**检验方法：念出来。** 念着别扭的地方，观众听着也别扭。
