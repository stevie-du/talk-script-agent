# 输出模板

## 输出结构（按顺序）

```
① 参数回执与字数配额
② 口播文案（format 含"口播"时输出）
③ 分镜表（format 含"分镜"时输出）
④ 合规检查报告
⑤ 拍摄与发布提示
```

---

## ① 参数回执与字数配额

```markdown
**主题**：{topic}
**细分 / 受众**：{segment} / {audience}
**目标时长 / 平台 / 风格**：{duration}s / {platform} / {style}
**人设**：{persona}

**字数配额**：目标 {target} 字（语速 {rate} 字/秒）
- 开场钩子 {a} 字
- 正文要点 {b} 字（{n} 个要点）
- 结尾引导 {c} 字
```

---

## ② 口播文案

```markdown
## 口播文案

**【开场钩子】** 0-3 秒 · {a} 字
{文案}

**【要点一】** {起始}-{结束} 秒 · {n} 字
{文案}

**【要点二】** {起始}-{结束} 秒 · {n} 字
{文案}

**【要点三】** {起始}-{结束} 秒 · {n} 字（仅 60s 及以上保留）

**【结尾引导】** {起始}-{结束} 秒 · {c} 字
{文案}

---
**字数统计**：{实际} / {目标} 字
**预估时长**：{秒} 秒（偏差 {百分比}）
```

### 标注规则
- 需要停顿处用 `／` 标记
- 需要重读的词用 **加粗**
- 需要画面配合处用 `[画面：xxx]` 内联标注
- 占位事实统一用 `{{待补：xxx}}`

---

## ③ 分镜表

| 镜号 | 时长 | 画面 / 景别 | 口播文案 | 字幕关键词 | 音效 / BGM | 拍摄提示 |
|---|---|---|---|---|---|---|
| 1 | 0-3s | {景别与内容} | {文案片段} | {≤12字} | {音效} | {提示} |
| 2 | 3-8s | | | | | |
| ... | | | | | | |

### 分镜填写要求
- **画面**必须可实拍，写清景别（特写 / 中景 / 全景 / 跟拍 / 俯拍）
- **字幕关键词**不是口播原文，是放大的重点，每屏 ≤ 12 字
- **拍摄提示**写清场地、道具、安全注意事项
- 涉及电梯内部结构的画面，提示"需维保单位配合，禁止无资质人员操作"

---

## ④ 合规检查报告（必输出）

```markdown
## 合规检查

| 检查项 | 结果 |
|---|---|
| 广告法禁用词 | 通过 / 命中 N 项已修正 |
| {platform} 平台规则 | 通过 / 命中 N 项已修正 |
| 电梯行业红线 | 通过 / 命中 N 项已修正 |
| 事实依据 | 全部有来源 / 含 N 处占位符 |
| 字数与时长 | 合格 / 偏差 {百分比} |

**修正记录**：
- {原表述} → {修正后}（原因：{理由}）

**待补事实**：
- {{待补：xxx}} — 需要你提供
```

若有占位符，必须在报告后追加提示：
> 以上脚本含 N 处占位事实，请补充后再发布。不要用估算值填充。

---

## ⑤ 拍摄与发布提示

```markdown
## 拍摄提示
- {与内容相关的具体提醒}

## 发布提示
- 平台：{platform}
- 建议标题：{1-2 个}
- 话题标签：{#xxx #xxx}
- 需标注内容：{AI生成 / 虚构演绎 / 商业推广 / 无需标注}
- 评论区预设：{引导评论的关键词}
```
