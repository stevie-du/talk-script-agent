# 电梯行业红线、反谣言库与统一口径

## 1. 安全承诺红线（绝对禁止）

以下表述一律不得出现：

- 绝对安全、100% 安全、万无一失
- 零事故、零故障、零困人
- 永不困人、永不故障、永久免维护、终身不出问题
- 出事包赔、伤亡全赔

**原因**：既是广告法绝对断言，也违反特种设备行业的审慎原则。电梯是特种设备，任何负责任的从业者都不会做绝对承诺。

**安全相关表述的正确姿势**：讲**装置**和**机制**，不讲**结果保证**。
✅ `电梯上装了限速器和安全钳，一旦速度异常，安全钳会把轿厢卡在导轨上。`
❌ `所以电梯绝对不会掉下去。`

## 2. 危险行为禁演清单

脚本中**不得描述、演示、暗示**以下行为，包括"反面演示"：

- 扒开轿门或层门、用手掰门、用物品卡门
- 攀爬轿顶、从轿顶逃生、在井道内行动
- 短接门锁、屏蔽安全回路、旁路安全装置
- 无证人员自行检修、更换部件、调整参数
- 轿厢内蹦跳打闹的危险演示
- 强行阻止关门、长时间挡门

**替代做法**：只描述后果和正确做法，不描述操作细节。

## 3. 反谣言库

生成科普内容前先自查，主动纠正以下常见误解。注意：**辟谣时要给机制解释，不能只否定**。

| 常见说法 | 事实 | 正确表述 |
|---|---|---|
| 电梯会自由落体掉下去 | 有多重机械保护，真正坠落极罕见 | 电梯有抱闸、限速器和安全钳，速度异常时安全钳会把轿厢制停在导轨上；还有缓冲器作为最后一道保护 |
| 被困会窒息 | 轿厢非密闭，有通风结构 | 轿厢不是密闭空间，有通风口，不会因为缺氧窒息 |
| 要扒门自救 | 极易坠入井道 | 轿厢可能停在两层之间，扒门有坠入井道的风险，一定要等专业人员 |
| 蹦跳会导致坠梯 | 不会导致坠落，但可能触发保护停梯 | 蹦跳可能让电梯保护性停梯，造成被困，但不会导致坠落 |
| 门夹人会一直夹 | 有光幕或安全触板 | 门有光幕或安全触板，感应到障碍会重新打开 |
| 闻到焦味要马上砸门 | 错误，应报警等待 | 立即按警铃联系外界，说明情况，等待专业人员处理 |
| 下蹲抱头能保命 | 不是标准姿势 | 如真遇异常，背靠轿壁、膝盖弯曲缓冲，是更合理的姿势 |

**辟谣类内容在视频号尤其注意**：禁用"唯一真相""辟谣所有""绝对正确"等极端科普话术（见 `platform.md`）。

## 4. 统一救援口径（唯一标准答案）

涉及"被困怎么办"时，必须按以下顺序输出，不得增删：

1. 保持冷静，按轿厢内的**警铃**或**对讲按钮**，联系值班人员
2. 无人应答时，拨打电梯内**公示的应急救援电话**，或当地电梯应急救援服务电话
3. 说清楚：**小区名称、楼栋单元、电梯编号**
4. **原地等待**，不要扒门、不要自行攀爬
5. 专业人员到达前，不做任何自救动作

**注意**：
- 不要写死"96333"——该号码并非全国统一，不同城市不同。写"当地电梯应急救援服务电话"，用户指定城市时再写具体号码。
- 不要说"打 119"作为首选项，只在"出现火情"等真正紧急场景下才提及。

## 5. 术语规范（禁用口语化错误说法）

| 错误说法 | 规范术语 |
|---|---|
| 电梯刹车 | 制动器 / 抱闸 |
| 电梯绳子、钢缆 | 钢丝绳 / 悬挂装置 |
| 电梯电脑板 | 控制柜 / 主控板 |
| 防坠装置 | 限速器 - 安全钳联动装置 |
| 电梯年检 | 定期检验（另有"自行检测"） |
| 电梯保险 | 安全保护装置（并说明具体类型） |
| 电梯机房的马达 | 曳引机 |
| 电梯门感应 | 光幕 / 安全触板 |
| 电梯配重 | 对重 |

## 6. 维保周期口径

按 TSG T5002《电梯维护保养规则》，维保项目分为**半月、季度、半年、年度**四类。
生成维保科普内容时，周期表述必须落在这四类上，不要自造"每月维保""双周维保"等说法。

## 7. 资质与作业边界

**不得输出**：具体拆机步骤、接线方法、参数调整数值、故障码清除流程。
**原因**：电梯属特种设备，相关作业需持证进行，公开教程存在法律风险。

科普可以讲**原理**和**周期**，不可以讲**操作方法**。

## 8. 敏感话题处理

| 话题 | 处理方式 |
|---|---|
| 电梯事故 | 不描述伤亡细节、不点名小区和当事人、不用事故画面博眼球 |
| 物业与维保纠纷 | 不煽动对立、不做法律定性、建议通过正规渠道反映 |
| 竞品对比 | 不点名、不贬损、不暗示同行不安全 |
| 政府补贴政策 | 不写"政府扶持""官方补贴"，写"符合条件的老旧小区可申请财政补助，以当地政策为准" |
| 加装电梯邻里矛盾 | 保持中立，不站队，强调沟通与合规流程 |
