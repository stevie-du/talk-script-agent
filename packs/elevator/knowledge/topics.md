## 1. 维保（segment: 维保）

### 核心知识点
- 维保周期按 TSG T5002 分为四类：**半月、季度、半年、年度**
- 维保内容界定：清洁、润滑、检查、调整、更换易损件；**不含**安装、改造、修理
- 使用单位义务：委托有资质单位、建立安全技术档案、张贴检验标志与警示标志、制定应急措施
- 维保记录：需留痕，是责任划分的关键依据

### 常见故障现象（选题素材）
异响抖动 / 平层不准 / 开关门异常 / 按钮失灵 / 突然停梯 / 轿厢照明通风异常 / 楼层显示错乱

### 常见误区（可做辟谣选题）
| 误区 | 事实 |
|---|---|
| 不出故障就不用维保 | 维保是预防性的，等出故障已经晚了 |
| 维保就是擦擦油 | 含制动器、限速器、门系统、安全部件的功能检查 |
| 维保记录随便签 | 记录是事故责任认定的关键证据 |
| 维保越快越好 | 项目数量和标准是固定的，过快说明没做全 |

### 行业现实（需谨慎表述，不做绝对判断）
低价竞争、维保工流动性大、单台维保工时被压缩——可讲现象，不点名、不做定性指控。

### 需占位的事实
维保费区间、单台维保工时、故障率、响应时长 → `{{待补}}`

## 2. 旧楼加装（segment: 旧楼加装）

### 流程（简化版）
意见征询 → 方案设计与公示 → 规划审批 → 管线迁改 → 土建施工 → 电梯安装 → 验收 → 使用登记

### 关键技术与条件
- **底坑深度**、**顶层高度**：能否加装的首要硬条件
- **管线迁改**：水电气、通信，常是预算超支主因
- **承重与结构**：需原建筑结构鉴定
- **消防通道**：不得占用、不得降低原有疏散条件
- 井道形式：钢结构井道（最常见）、混凝土井道
- 入户方式：**平层入户**（直接进家门，体验好、改动大）/ **半层入户**（错层半层，改动小）

### 协调难点（高共鸣选题）
- 一二楼反对：采光、噪音、隐私、房价预期
- 费用分摊：常见按**楼层系数**递增（越高出越多），具体方案业主协商
- 后期运维：电费、维保费、年检费谁出，最容易埋雷

### 政策口径（红线区）
✅ `符合条件的老旧小区可申请财政补助，具体标准和流程以当地政策为准`
❌ `政府扶持` `官方补贴` `政府给钱`（权威冒用，违规）

### 常见误区
| 误区 | 事实 |
|---|---|
| 一楼一定反对 | 加装后无障碍通行对老人同样有利，关键在沟通与补偿方案 |
| 加装会破坏楼体结构 | 需做结构鉴定，合格才施工；独立基础可降低影响 |
| 加装后房价必涨 | 受楼层、朝向、市场环境多重影响，不做承诺 |
| 少数服从多数就行 | 各地对表决比例有不同规定，需按当地规则执行 |

### 需占位的事实
总造价区间、分摊案例、申请周期、本地政策 → `{{待补}}`

## 4. 家用电梯（segment: 家用电梯）

### 重要区分（易错点，需核实后使用）
家用电梯（仅供单一家庭使用）与商用电梯在**监管属性**上存在差异，家用电梯一般不纳入特种设备目录管理。
⚠️ **该表述涉及法规界定，发布前请核实当地监管口径**，不确定时改为：`家用电梯和商用电梯在标准和监管要求上不一样，购买前要问清楚。`

### 驱动方式对比（选型类选题核心）
| 类型 | 特点 | 适用场景 |
|---|---|---|
| 曳引式 | 运行平稳、能耗低、速度快，需井道和底坑 | 有预留井道或可开挖 |
| 螺杆式 | 结构简单、可无底坑、速度较慢 | 空间受限、无法下挖 |
| 液压式 | 载重大，存在漏油风险，已较少 | 特殊需求 |

### 关键参数
载重（常见 250~400kg）、速度（常见 0.15~0.4 m/s）、井道尺寸、底坑深度、顶层高度
→ 具体数值 `{{待补}}`，以产品手册为准

### 安装前置条件
预留井道 / 有无底坑方案 / 顶层净高 / 电源条件 / 楼板开孔

### 常见误区
| 误区 | 事实 |
|---|---|
| 家用电梯不用保养 | 仍需定期检查保养，只是不强制法定检验 |
| 越便宜越好 | 驱动方式、安全配置、售后网络差异大 |
| 随时能装 | 受井道、底坑、顶层高度限制，需提前测量 |

## 5. 自动扶梯（segment: 扶梯）

### 标准
GB 16899-2011《自动扶梯和自动人行道的制造与安装安全规范》

### 安全装置（科普素材）
梳齿板安全装置 / 扶手带入口保护 / 围裙板保护 / 逆转保护装置 / 紧急停止按钮 / 梯级缺失保护

### 乘梯要点
站稳扶好 / 站在梯级黄线内 / 不逆行奔跑 / 不攀爬扶手带 / 儿童牵好不独乘 / **婴儿车、购物车不推上扶梯**（应乘垂直电梯）

### 高风险人群与场景
儿童（围裙板、梳齿板夹伤风险最高）/ 老人（平衡能力）/ 长裙、软底鞋 / 携带大件行李

### 紧急停止按钮
位于扶梯上下两端扶手下方，红色。强调：**正常运行中不得随意按压**

### 常见误区
| 误区 | 事实 |
|---|---|
| 扶梯会突然逆转 | 有逆转保护装置 |
| 靠右站是规定 | 部分城市不提倡长期单侧站立（磨损不均），以现场指引为准 |
| 夹到会一直夹 | 安全装置触发后会停止 |

## 6. 零部件（segment: 零部件）

### 钢丝绳
报废技术条件见 GB/T 31821-2015《电梯主要部件报废技术条件》，判据涉及断丝、磨损、锈蚀、变形。
**注意**：不输出具体判废数值。

### 其他关键部件
- **制动器（抱闸）**：断电自动抱死，安全核心部件
- **限速器 - 安全钳**：超速保护的机械联动装置，需定期校验（校验周期 `{{待补}}`）
- **门系统**：光幕 / 安全触板防夹，门机控制
- **曳引机**：永磁同步为主流（能效）
- **缓冲器**：井道底部最后一道保护

## 7. 检验检测（segment: 检验检测）

### 周期与类型
- **定期检验**：按 TSG T7001-2023 执行，每年一次
- **自行检测**：按 TSG T7008-2023 执行
- 检验标志应张贴在轿厢内显著位置

### 选题角度
检验标志上的日期怎么看 / 检验不合格怎么办 / 自行检测和定期检验的区别 / 使用登记表在哪

### 常见误区
| 误区 | 事实 |
|---|---|
| 检验合格就永远安全 | 检验是时点结论，日常维保才是持续保障 |
| 检验就是走过场 | 有明确的检验项目和判定规则 |

## 8. 安全科普（segment: 通用）

### 高频话题
被困怎么办（用统一救援口径）/ 会窒息吗 / 会坠落吗 / 门夹人怎么办 / 超载了怎么办 / 电动车能不能进电梯 / 宠物绳被夹 / 小孩在轿厢蹦跳

### 电动车进梯（热点，注意表述）
风险是**电池起火**，且轿厢相对封闭、逃生困难。注意：科普中不要说"轿厢是密闭空间"（与反谣言库"轿厢非密闭、有通风口"冲突），起火场景用"相对封闭、烟气不易散出"表述。
表述：`建议不要将电动自行车推入轿厢，电池起火风险高，且轿厢内逃生困难。`
不做绝对禁止性法律定性，用建议语气。

### 禁止行为清单（脚本可直接使用）
不扒门 / 不蹦跳 / 不用物品挡门 / 不超载 / 不倚靠轿门 / 不在轿厢内吸烟 / 不随意按压紧急按钮
