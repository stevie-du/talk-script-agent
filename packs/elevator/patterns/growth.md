# 完播与转化：电梯口播特有的取舍

通用短视频常识（前 3 秒、字幕 ≤12 字、删铺垫、不口号式收尾）已经固化在
`skill.yaml` 的口语化硬规则里，本文件只写**这个行业特有、规则里没有**的部分。

## 一、信任：高客单价、低频、强信任依赖，观众不会冲动下单

素材可信度排序 —— **每提一个卖点，配一个证据；没有证据的卖点宁可不写**：

| 可信度 | 素材 |
|---|---|
| 高 | 具体案例（小区 / 台量 / 时间），数字只能来自私有资料，缺就写 `{{待补：小区}}` |
| 高 | 可验证数据（响应时长、在保台量）与资质、从业年限 |
| 中高 | 专业细节：把机制讲透，讲得越透越可信 |
| 低 | 形容词（专业、靠谱、品质）—— 几乎无效 |

## 二、节奏：一个要点是一段，但一段不等于只讲一件事

一个要点的配额约 63 字（60s 档）到 150 字（180s 档），也就是 14~33 秒。
**这一段里每 10~15 秒要落一个新信息** —— 转折、例子、数字或画面变化；
一口气讲到底不断档，是中段划走的主因。60 秒以上的片子在 40% 进度处再补一次钩子。

## 三、CTA：电梯服务的三个约束

- 一次只给一个动作，给三个等于没给。
- **领资料 / 领报价表**最合适：门槛低，又能筛出正在决策的人；
  预约上门勘测偏重，留给本地客户和大单。
- 强地域属性，CTA 带地域信号：`我们在{{待补：城市}}市区，{{待补：响应时长}} 内到场`。
- 泛科普只吸引泛流量：`电梯为什么要定期维保` 不如
  `你家小区的维保记录在哪查、多久一次`（后者是正在管这事的人）。
- 紧迫感只能用真实活动 + 确切起止日期；"最后一天""马上涨价"属虚假营销，禁用。
