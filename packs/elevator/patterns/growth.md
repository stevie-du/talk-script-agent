# 完播率与转化率设计要点

## 一、完播率：影响最大的 8 个因素

### 1. 前 3 秒钩子（权重最高）
完播率的绝大部分差异在开场。详见 `hooks.md`。
**硬规则**：第 1 个字就要有信息或冲突，0 铺垫。

### 2. 信息密度与节奏
- 每 **10~15 秒**必须出现一个新信息点、转折或画面变化
- 60 秒以上的内容，在 **40% 进度处补一次钩子**（`这里有个细节，90% 的人都忽略了`）
- 语速和音量要有起伏，平铺直叙会掉人

### 3. 开放回路（Open Loop）
开头抛出问题 → 明确告诉观众答案在后面 → 中间不揭晓。
```
钩子：`被困电梯，第一件事做什么？九成人做错了。`
中段：先讲错误做法和后果
后段：才给正确做法
```
**注意**：回路必须在视频内闭合，不能骗观众看到最后却没有答案——会被反噬。

### 4. 预期管理
开头就告诉观众这条视频的"结构"，降低中途放弃率：
- `就三句话，听完你就明白了`
- `关键就一个动作`
- `分两种情况，你对照着看`

### 5. 零废话
**删掉**：背景铺垫、行业现状、自我介绍、"随着XX的发展"、重复强调。
判断标准：删掉这句话，后面的内容还成立吗？成立就删。

### 6. 时长与内容匹配
内容撑不住时长时**缩短时长**，不要注水。15 秒能讲清的就别做 60 秒。

### 7. 结尾不要提前"结束"
❌ `以上就是今天的分享，记得点赞关注` —— 说完这句观众立刻划走，且平台会判定为内容结束信号。
✅ 把 CTA 嵌在最后一句信息里，或者用悬念式收尾。

### 8. 字幕与听觉节奏
- 字幕不是口播原文照搬，是**关键词放大**
- 每屏字幕不超过 12 个字
- 关键数字、动作、禁用行为要单独放大

### 完播率杀手清单（自查）
- [ ] 开场有自我介绍或寒暄
- [ ] 前 5 秒出现 logo、片头、品牌名
- [ ] 背景铺垫超过 2 句
- [ ] 语速全程无变化
- [ ] 有重复表述（同一意思说了两遍）
- [ ] 结尾出现"以上就是……记得点赞关注"
- [ ] 钩子抛出的问题，最后没回答

## 二、转化率：影响最大的 7 个因素

### 1. 信任建立（电梯行业最关键）
电梯是**高客单价、低频率、强信任依赖**的品类，观众不会冲动下单。
建立信任的素材按可信度排序：

| 素材 | 可信度 | 说明 |
|---|---|---|
| 具体案例（小区、台量、时间） | 高 | `去年我们在XX小区换了 12 台` |
| 可验证数据（响应时长、台量） | 高 | 必须有 `facts` 支撑 |
| 资质与年限 | 高 | 持证、从业年限 |
| 专业细节（讲清机制和原理） | 中高 | 讲得越透越可信 |
| 用户评价 | 中 | |
| 形容词（专业、靠谱、品质） | 低 | **几乎无效，少用** |

**核心原则**：**每提一个卖点，配一个证据**。没有证据的卖点宁可不写。

### 2. 痛点精准度
泛科普吸引泛流量。转化内容必须命中**正在决策**的人：
- ❌ `电梯为什么要定期维保`（所有人，但不着急）
- ✅ `你家小区的维保记录，应该在哪里查，多久一次`（物业/业委会，正在管这事）

### 3. CTA 单一明确
**一次只给一个动作**。给三个选择等于没给。

### 4. 行动门槛梯度（从低到高）

| CTA | 门槛 | 适合阶段 |
|---|---|---|
| 评论区扣关键词 | 最低 | 冷启动、测需求 |
| 关注 | 低 | 养号期 |
| 私信咨询 | 中 | 有明确意向 |
| 领资料 / 领报价表 | 中 | **电梯行业最推荐** |
| 预约上门勘测 / 免费检测 | 较高 | 本地客户 |
| 到店 / 面谈 | 最高 | 大客户 |

### 5. 价值前置
先给东西，再要东西。
✅ `我把维保检查清单整理好了，评论区扣"清单"，我发给你`
❌ `想了解的私信我`

### 6. 紧迫感（合规范围内）
- ✅ 真实活动必须写明确切起止日期
- ❌ 禁止"最后一天""马上涨价""错过再等一年"（见 `ad-law.md`）

### 7. 本地化
电梯服务有强地域属性，CTA 要带地域信号：
`我们在XX市区，两小时内到场` / `XX市的老小区，我们做过XX个`

## 三、完播率与转化率的平衡

两者存在天然矛盾，需要按账号阶段配比：

| 账号阶段 | 内容配比 | 目标 |
|---|---|---|
| 冷启动（0-1 万粉） | 90% 泛科普 + 10% 转化 | 先跑完播率拿流量 |
| 成长期（1-10 万粉） | 70% 科普 + 30% 转化 | 建立专业人设，开始收线索 |
| 成熟期 | 50% 科普 + 50% 转化 | 稳定产出线索 |

**选题判断**：
- 追完播 → 选大众焦虑话题（安全、困人、维保黑幕）
- 追转化 → 选决策场景话题（报价、选型、加装流程、验收标准）

## 四、生成后自检清单

**完播维度**
- [ ] 第 1 句有没有钩子
- [ ] 每 10-15 秒有没有新信息
- [ ] 有没有废话可以删
- [ ] 结尾是不是自然的

**转化维度**
- [ ] 有没有具体证据（不是形容词）
- [ ] CTA 是不是只有一个
- [ ] 有没有先给价值
- [ ] 目标人群是不是正在决策的人
