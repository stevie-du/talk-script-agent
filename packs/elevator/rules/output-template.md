# 输出模板

> **本文件面向「成品排版」与人工交付**：成稿与人工交付都照下面的 ①~⑤ 版式。
>
> **模型输出的结构契约不在这里** —— 撰写阶段返回什么由 `skill.yaml` 的
> `stages.write` / `stages.storyboard` 模板规定，落盘字段由 `app/schemas.py`
> （`ScriptResult`：`sections` / `storyboard` / `scenes` / `timings` / `check` / `quota`）
> 规定，引擎自己的 `脚本.md` 由 `app/store.py` 渲染。这里**不再重复一份 JSON schema**：
> 第三份结构必然与前两份漂移（此前就是它同时给了 `audio`+`sfx` 两个字段，
> 而契约里只有一个 `sfx`）。

## 输出结构（按顺序）

```
① 参数回执与字数配额
② 口播文案（format 含"口播"时输出）
③ 分镜表（format 含"分镜"时输出）
④ 合规检查报告
⑤ 拍摄与发布提示
```

---

## ① 参数回执与字数配额

```markdown
**主题**：{topic}
**细分 / 受众**：{segment} / {audience}
**目标时长 / 平台 / 风格**：{duration}s / {platform} / {style}
**人设**：{persona}

**字数配额**：目标 {target} 字（语速 {rate} 字/秒）
- 开场钩子 {a} 字
- 正文要点 {b} 字（{n} 个要点）
- 结尾引导 {c} 字
```

---

## ② 口播文案

```markdown
## 口播文案

**【开场钩子】** 0-3 秒 · {a} 字
{文案}

**【要点一】** {起始}-{结束} 秒 · {n} 字
{文案}

**【要点二】** {起始}-{结束} 秒 · {n} 字
{文案}

**【要点三】** {起始}-{结束} 秒 · {n} 字
{文案}

**【结尾引导】** {起始}-{结束} 秒 · {c} 字
{文案}

---
**字数统计**：{实际} / {目标} 字
**预估时长**：{秒} 秒（偏差 {百分比}）
```

### 标注规则
- 需要停顿处用 `／` 标记
- 需要重读的词用 **加粗**
- 需要画面配合处用 `[画面：xxx]` 内联标注
- 占位事实统一用 `{{待补：xxx}}`
- 上面示例固定摆了三条要点，**实际要点数按 `pack.yaml` 的 `points_by_duration`**
  （15s→1、30s→2、60/90s→3、180s→4）

## ③ 分镜表

| 镜号 | 时长 | 画面 / 景别 | 口播文案 | 字幕关键词 | 音效 / BGM | 拍摄提示 |
|---|---|---|---|---|---|---|
| 1 | 0-3s | {景别与内容} | {文案片段} | {≤12字} | {音效} | {提示} |
| 2 | 3-8s | | | | | |
| ... | | | | | | |

### 分镜填写要求
- 列与字段的对应：时长=`time`、画面/景别=`shot`、口播文案=`voiceover`、
  字幕关键词=`subtitle`、音效/BGM=`sfx`、拍摄提示=`note`。
  **音频只有 `sfx` 一个字段**（BGM 建议写进同一格），不另起 `audio` 列/字段
- **画面**必须可实拍，写清景别（特写 / 中景 / 全景 / 跟拍 / 俯拍）
- **字幕关键词**不是口播原文，是放大的重点，每屏 ≤ 12 字
- **拍摄提示**写清场地、道具、安全注意事项
- 涉及电梯内部结构的画面，提示"需维保单位配合，禁止无资质人员操作"

## ④ 合规检查报告（必输出）

```markdown
## 合规检查

| 检查项 | 结果 |
|---|---|
| 广告法禁用词 | 通过 / 命中 N 项已修正 |
| {platform} 平台规则 | 通过 / 命中 N 项已修正 |
| 电梯行业红线 | 通过 / 命中 N 项已修正 |
| 事实依据 | 全部有来源 / 含 N 处占位符 |
| 字数与时长 | 合格 / 偏差 {百分比} |

**修正记录**：
- {原表述} → {修正后}（原因：{理由}）

**待补事实**：
- {{待补：xxx}} — 需要你提供
```

若有占位符，必须在报告后追加提示：
> 以上脚本含 N 处占位事实，请补充后再发布。不要用估算值填充。

```markdown
## 发布提示

- 话题标签：{#xxx #xxx}

- 评论区预设：{引导评论的关键词}
```
